Geist: @fontsource-variable/geist 5.3.0 (FastUI comparison option)
https://github.com/vercel/geist-font
License: geist.txt

Unmodified WOFF2 files are emitted by Vite from the pinned font packages.
CSS Unicode ranges load the subsets required by the displayed text.
No external font service is requested at runtime.
