# The Web Conference 2026 Research Tracks

## Hard constraints

- Use the ACM two-column template and submit one PDF using `acmart` `sigconf, anonymous, review`; the main paper is 8 pages and the total, including references and optional appendix, is at most 12 pages.
- Review is double blind. Remove names, affiliations, acknowledgements, self-identifying references, and other identity clues; cite authors' prior work in the third person.
- State Web relevance and track relevance on the first page. Mere use of a Web artifact without a Web research question is out of scope and desk-rejected.
- Submit original work not under review or published at an archival venue. Follow ACM authorship policy: LLMs cannot be authors and authors remain responsible for paper text.
- Follow ACM policies for human participants; include ethical use of data/informed-consent material when appropriate, and report IRB review/approval where applicable.

## Writing and review priorities

- Tie research question, method, evaluation, related work, reproducibility, and ethics to a concrete Web problem.
- Make the first eight pages self-contained because reviewers need not read later pages.

## Planning checklist

- Put Web/track relevance on page one and core evidence in the 8-page body.
- Audit anonymity, manuscript metadata, external links, and COI before submission.
- Verify data ethics, consent, and reproducibility evidence before making Web-scale claims.
