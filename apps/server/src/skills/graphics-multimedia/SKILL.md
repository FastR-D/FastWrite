# Computer Graphics and Multimedia

Read [references/profile.md](references/profile.md) and then the selected venue file. Keep visual evidence, user study or quantitative evaluation, rendering/system details, and citations traceable.

## Working rules

1. State the visual, geometric, multimedia, interaction, or visualization problem, novelty, assumptions, and evaluation criteria early.
2. Do not invent visual results, user-study participants, comparisons, artifact links, data, hardware, citations, permissions, or metrics.
3. Check that all figures/tables are cited, readable, licensed/credited where needed, and support the adjacent claim.
4. Treat active-cycle format rules as deterministic constraints only when the official venue document confirms them; otherwise report `uncertain`.
