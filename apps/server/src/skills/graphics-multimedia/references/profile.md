# Computer Graphics and Multimedia profile

Describe the contribution at the correct level: algorithm, geometry, rendering, animation, visual-analysis method, interaction technique, VR/AR system, or multimedia system. Explain what is new, what assumptions enable it, how it is implemented, and how it is evaluated against relevant alternatives. For quantitative work include datasets/scenes, parameter settings, hardware/software, metrics, variance and failure cases. For perceptual or interaction claims include study design, recruitment, task, measures, analysis, ethics, and threats to validity.

Use primary, verifiable sources. Cite original methods, datasets, software, visual assets and prior results; ensure that figure credits and third-party material permissions are documented. Never turn a visually plausible output into an unsupported empirical claim.
