# SIGGRAPH Technical Papers

## Hard constraints

- Use ACM double-column SIGGRAPH formatting; the official LaTeX submission form is `acmtog,anonymous,review` with an assigned submission ID. Use acmart 2.16+ and only TAPS-accepted packages.
- All initial material must be anonymous, including paper, video, data, code, figures, PDF metadata, acknowledgements, and URLs. Cite relevant own work completely but according to the detailed anonymous prior-art policy.
- Journal-only submissions have no fixed page limit. Dual-track submissions have at most 7 core pages excluding references, up to 2 figures-only pages after references, no appendix in the main PDF, and unlimited references; do not apply the dual-track limit to Journal-only work.
- Submit original non-concurrent work, disclose conflicts by the active deadline, and do not use format manipulation, tracking scripts, plagiarism, or uncredited source material.

## Writing and review priorities

- Journal-track work requires novel, well-validated, comprehensive advances; Conference-track work can have less complete evidence but must still establish a novel advance.
- Make methods, scenes/data, comparisons, perceptual/system evaluation, and limitations inspectable. Attribute external visual assets and prior techniques precisely.

## Planning checklist

- [ ] Choose Journal-only or dual-track before setting a page budget.
- [ ] For dual-track, place only figures/captions in permitted figures-only pages and put appendix material in supplement.
- [ ] Check source packages, PDF ID/page numbers, anonymity, visual credits, and every bibliography entry.
