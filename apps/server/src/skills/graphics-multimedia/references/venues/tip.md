# IEEE Transactions on Image Processing

## Hard constraints

- Follow the current IEEE TIP author center for the chosen article type, template, length/overlength, source files, declarations, ethics, copyright, and publication rules.
- Do not encode a static page or review-mode rule when not confirmed in the live author center.
- Obtain permission and attribution for reused images/data and comply with IEEE originality and authorship requirements.

## Writing and review priorities

- State the image-processing task, data/ground truth, algorithmic novelty, comparison protocol, metrics, visual evidence, and limitations.
- Avoid selective visual examples; report representative quantitative results and failure modes.

- [ ] Verify current TIP format and article-type requirements before submission.
