# Network and information security

Read `references/profile.md` and the selected venue file before working. Convert applicable hard constraints to explicit checks. Do not invent attacks, proofs, measurements, artifacts, vulnerabilities, citations, or compliance results.

## Workflow

1. Identify venue, edition, track, and submission stage.
2. Check anonymization, template, page budget, ethics, artifacts, and overlap policy before prose changes.
3. Keep threat model, assets, trust boundaries, assumptions, and evaluation evidence mutually consistent.
4. Preserve technical notation and citation keys when revising.
5. Report violations and uncertainty with the controlling official source.

## Citation integrity

Never invent a reference, CVE, standard, vulnerability report, or artifact citation. Verify each bibliographic record against an authoritative publisher, DOI, registry, or official issuer and verify that it supports the cited security claim. Flag malformed, unreachable, retracted, duplicate, misattributed, or claim-mismatched references rather than silently repairing them.
