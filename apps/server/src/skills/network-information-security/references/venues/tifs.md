# IEEE Transactions on Information Forensics and Security (TIFS)

## Hard constraints

- Use the current IEEE Transactions template and IEEE editorial/reference style; submit through the IEEE Author Portal with the files and declarations it requests.
- Submit original, non-duplicate work and disclose related conference papers, preprints, datasets, and contemporaneous submissions as required by the live IEEE workflow.
- TIFS length and overlength policy are article-type and policy-version dependent. The public journal page does not provide one current hard submission-page cap; set the budget only after checking the live Author Portal and current Information for Authors, rather than importing limits from another IEEE Transactions title.
- Supply supplementary or multimedia material as separately identified files when used; do not make the central result depend on inaccessible supplementary content.
- Comply with IEEE ethics, permissions, conflict/funding disclosures, and plagiarism screening requirements.

## Writing and review priorities

- Establish a precise forensics or security question and specify the data provenance, threat model, attacker knowledge, and decision setting.
- Make evaluation reproducible: report data splits, preprocessing, training/inference details, metrics, implementation choices, and uncertainty or robustness analysis.
- For deep-learning work, include the information needed to reproduce results, consistent with TIFS's dedicated reproducibility guidance.
- Test attacks, countermeasures, and detectors under credible adaptive or distribution-shift conditions; separate security guarantees from benchmark performance.
- Explain practical significance, limitations, misuse risks, and how artifacts/code/data can be accessed or why they cannot be shared.

## Planning checklist

- [ ] Select the TIFS manuscript type and verify its live length/overlength policy in the official portal before final compression.
- [ ] Use the current IEEE template and keep references, figures, and tables in the required manuscript form.
- [ ] Document data provenance, licenses, consent/privacy constraints, and every split or preprocessing decision.
- [ ] Include adaptive-attack, robustness, ablation, and failure analysis appropriate to the security claim.
- [ ] Provide reproducibility artifacts or an explicit, defensible availability limitation; declare all conflicts, funding, and reused material.
