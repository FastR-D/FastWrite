# Information and Computation

## Hard constraints

- Follow the current Elsevier Guide for Authors: editable source files are required, LaTeX is encouraged, and math must be editable text rather than images.
- Provide title-page/author data and mandatory declarations in the journal workflow; number sections and equations consistently. Use footnotes sparingly and put acknowledgements immediately before references.
- Cite every in-text reference and list every bibliography entry cited; reference data must be complete and accurate. The guide accepts a consistent submission style and recommends DOI links.

## Writing and review priorities

- Target original results in theoretical CS or computational information-theory applications; make proofs and boundaries of applicability complete.
- Present theory/calculation in a reproducible, unambiguous form.

## Planning checklist

- [ ] Supply editable LaTeX/figure/table sources and check equations are not images.
- [ ] Check citations bidirectionally and validate names, venues, years, pagination, and DOIs.
- [ ] Reopen the live Guide for Authors for any article-type-specific declaration or length rule.
