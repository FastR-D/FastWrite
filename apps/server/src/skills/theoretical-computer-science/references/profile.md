# Theoretical Computer Science profile

Make the central result legible early: problem, model, prior bound or barrier, theorem, significance, and technical idea. Give enough proof structure for a broad theory audience to verify why the theorem follows; do not move indispensable reasoning into an appendix that the venue need not read. Check quantifiers, parameter regimes, randomness/adversary assumptions, reductions, constants where material, and whether lower/upper bounds actually match the stated claim.

Use primary references and complete bibliographic records. A citation supports only the claim it actually establishes; cite the original theorem/version where possible, do not create references from model memory, and surface missing verification.
