# Theoretical Computer Science

Read [references/profile.md](references/profile.md), then the chosen venue file. Never replace a proof obligation with confident prose, and never infer active-cycle formatting from a prior call.

## Working rules

1. State definitions, models, assumptions, theorem scope, and asymptotic notation before relying on them.
2. Main claims need sufficient proofs or clearly labelled proof pointers; never invent a lemma, lower bound, reduction, citation, or result.
3. Cite original sources for known results and distinguish a theorem that is proved in the manuscript from one used as prior work.
4. When page, template, review, or publication rules are not in the official current source, mark them `uncertain` and require live verification.
