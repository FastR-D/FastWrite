# Computer Architecture, Parallel/Distributed Computing, and Storage

Read [references/profile.md](references/profile.md) and the selected venue file before drafting or reviewing. Venue rules override this shared guidance. Preserve LaTeX, technical terminology, measurements, citations, and claimed evidence; never invent experiments, systems, citations, or results.

## Workflow

1. State the workload, machine/system model, assumptions, and comparison point before asserting performance or scalability.
2. Make hardware, compiler, OS, storage, topology, configuration, data set, and measurement methodology reproducible.
3. Separate measured effects from causal explanations; report variance, limitations, negative results, and threats to validity.
4. Treat a venue's page, anonymity, template, artifact, and checklist rules as submission blockers, not prose preferences.
