# IEEE Transactions on Computers

## Hard constraints

- Follow the live IEEE/TC manuscript template, submission, rights, and ethics instructions.
- A universal page cap is not recorded because it depends on the current TC article type; verify it in the submission system.
- Disclose prior publications and use only sources that the authors have actually verified.

## Writing and review priorities

- Connect architecture or systems mechanism to a stated workload, methodology, and defensible performance/cost conclusion.
- Report baseline parity, hardware/software versions, variability, and limitations.

## Planning checklist

- [ ] Confirm article type, length, template, and required declarations.
- [ ] Audit figures, tables, and references for reproducibility and source integrity.
- [ ] Make unsupported claims explicit TODOs rather than filling them with plausible text.
