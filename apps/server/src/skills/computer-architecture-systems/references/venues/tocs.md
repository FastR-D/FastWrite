# ACM Transactions on Computer Systems

## Hard constraints

- Submit through the journal's current ACM workflow and use the currently required ACM article template and rights process.
- TOCS does not publish a fixed universal page limit in the shared ACM author instructions; obtain the handling editor's and current journal's limit before treating length as compliant.
- Verify the current policy for prior conference versions, supplementary material, anonymization, data/code, and conflicts at submission time.

## Writing and review priorities

- Establish a durable systems contribution with a precise model, implementation detail, rigorous evaluation, and clear limitations.
- Make comparison configurations, workloads, resource costs, and statistical treatment reproducible.

## Planning checklist

- [ ] Confirm article type, length expectation, ACM template, and disclosure policy from the live journal portal.
- [ ] Link every performance claim to an experiment, configuration, and reproducible artifact or justified exception.
- [ ] Check that every citation exists and supports the exact claim it is attached to.
