# Computer Networks

Read [references/profile.md](references/profile.md) and the selected venue file first. Current venue requirements override shared advice. Preserve protocol terms, equations, measurements, citations, and LaTeX; never invent traces, deployments, baselines, citations, or results.

## Workflow

1. State the network model, threat/failure assumptions, topology, workload/trace provenance, and deployment setting.
2. Make baseline configurations, testbed/simulator versions, metrics, and statistical treatment reproducible.
3. Separate observed behavior from causal explanation and generalization claims.
4. Treat the venue's current template, page, anonymity, artifact, and ethics requirements as hard gates.
