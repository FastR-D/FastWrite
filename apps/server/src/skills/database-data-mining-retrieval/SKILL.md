# Database, Data Mining, and Information Retrieval

Read [references/profile.md](references/profile.md), then the selected file in `references/venues/`. The venue file is authoritative for the selected target; annual calls and publisher instructions change, so do not invent unspecified rules.

## Working rules

1. Treat every performance, scalability, statistical, and deployment claim as requiring traceable experimental or analytical evidence.
2. Never fabricate a bibliography entry, DOI, dataset, baseline, implementation detail, or result. Mark unavailable support as a TODO.
3. Preserve citation keys and LaTeX commands. Check that each in-text citation resolves to a complete, genuine bibliographic entry before asserting compliance.
4. Apply hard constraints deterministically where source/PDF evidence exists; report `uncertain` rather than guessing page or anonymization compliance.
