# KDD Research Track

## Hard constraints

- Submit an anonymous ACM two-column PDF: 8 content pages, then unlimited references and optional appendix; reviewers need not read beyond the first 8 pages.
- Double-blind review applies. Keep author identities, affiliations, acknowledgements, identifying self-citations, and repository identity out of the submission; author order is fixed after the deadline.
- Complete OpenReview profiles and declare COIs. Each author is limited to 7 research-track submissions per cycle and each submission must nominate a qualified reviewing author when one exists.
- Disclose generative-AI use as required by ACM/KDD; submit original non-concurrent work and do not falsify data, results, or citations.

## Writing and review priorities

- Demonstrate technical merit, originality, impact, execution, presentation, related-work coverage, reproducibility, and ethical handling of data.
- Put a falsifiable question, credible baselines, uncertainty/robustness checks, and limitations in the main eight pages.

## Planning checklist

- [ ] Freeze the author list and check every author profile/COI/reviewing obligation.
- [ ] Budget eight self-contained content pages; keep references-only pages free of added argument.
- [ ] Verify all citations, benchmark results, consent/ethics assertions, code and data links before submission.
