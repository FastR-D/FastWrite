# ICDE

## Hard constraints

- Use only the active ICDE CFP/template and its stated review mode, page budget, supplement and camera-ready requirements.
- Do not claim a fixed 2027 page limit or anonymity policy until the official call publishes it; this is an explicit `uncertain` constraint, not permission to ignore formatting.

## Writing and review priorities

- Establish a concrete data-engineering problem, technical novelty, correctness, realistic scale, and reproducible evaluation.
- Report baselines, datasets/workloads, resource configuration, and failure or validity limits precisely.
