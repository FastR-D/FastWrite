# SIGIR Full Papers

## Hard constraints

- Use the active SIGIR ACM format and double-anonymous review requirements. The 2026 Full-Papers rules permit no content other than references after page 9; wrong format, excess content, or obvious anonymity leaks risk desk rejection.
- Author lists cannot change after the abstract deadline. Complete each required OpenReview profile; the 2026 rule requires a DBLP/ORCID publication link for authors meeting its stated threshold.
- Use anonymous code/artifact links, cite prior work appropriately, and comply with ACM originality, plagiarism, and AI-use policies.

## Writing and review priorities

- Show a genuine information-retrieval contribution, not only a generic model result; specify corpus, query/task definition, relevance labels, metrics, baselines, and error analysis.
- Review emphasizes novelty, technical depth, elegance, practical/theoretical impact, and presentation.
