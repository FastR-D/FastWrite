# OSDI

## Hard constraints

- Follow the live OSDI CFP and official USENIX template; it is biennial and exact page, review, artifact, and registration rules must be checked for the active cycle.
- CCF scope is the full technical-paper track only.
- Observe the current anonymity, conflicts, ethics, prior-publication, and artifact-access rules.

## Writing and review priorities

- Present a complete operating-systems design with correctness, implementation, reliability/failure evidence, realistic performance, and operational costs.
- Keep essential evidence in the paper rather than relying on optional material.

## Planning checklist

- [ ] Confirm current OSDI constraints before page planning.
- [ ] Audit anonymous PDF, source metadata, links, repository history, and artifacts.
- [ ] Validate every cited system description and performance comparison.
